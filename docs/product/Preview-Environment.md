Preview Environment
===================

The Preview environment runs the imminent production release of the OpenDataDSL portal and server. It gives you the opportunity to try out new features and to test issues that have been resolved, before the release reaches your production environment.

---

## Accessing the Preview portal

The Preview portal is available at:

**[https://preview-portal.opendatadsl.com](https://preview-portal.opendatadsl.com)**

Sign in with your usual SSO login credentials. There is no separate account or registration needed for Preview.

:::tip
Open the Preview portal in a separate browser tab from your production portal so it is always clear which one you are working in.
:::

---

## What you can access

| Area | Access in Preview |
|-|-|
| Your preview data environment | Full access to your own preview [data environment](/docs/discovery/uploading-data#data-environments) |
| Public data | All public data is available |
| Public calendars | All public calendars are available |
| Public scripts | All public scripts are available |
| Other public resources | Available, as in production |
| Your other data environments | Not available |

The only data environment you can access in Preview is your own **preview** data environment. Your production environment and any other data environments (for example DEV or TEST) cannot be selected from the Preview portal.

:::note
Anything you create or save while using the Preview portal is stored in your preview data environment. It does not change the data in your production environment.
:::

---

## What to use it for

The Preview environment is the place to:

* **Try out new features** in the upcoming portal and server release before they go live
* **Test resolved issues** to confirm that a fix you have been waiting for works with your own workflows and data
* **Check your processes** such as scripts, reports and automations against the new release in your preview data environment
