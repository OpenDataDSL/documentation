# Message

A **Message** is a string with a numeric code, used to return a coded result from a script or function. It has all the properties and methods of a [Scalar](/docs/odsl/variable/scalar).

## Construction

|**Function**|**Description**|
|-|-|
|Message()|Creates a new coded message|

## Properties

|**Name**|**Description**|**Type**|
|-|-|-|
|code|Integer code for this coded message|Integer|
