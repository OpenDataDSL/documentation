# Extensions

Extensions add screens to the OpenDataDSL portal and Excel add-in for a particular job: building compositions, checking data quality, exporting data, managing scripts, promoting changes between environments and more. Each one has its own menu item, tabs and insight reports, and works with your own access rights.

Pick an extension below to see what it does and how to use it, step by step.

## Build your own

The extensions above are built in exactly the same way as the ones you can build yourself, with a Fusion AI playbook or by hand. See [How extensions work](/docs/odsl/extension/extension-basics) to get started.
